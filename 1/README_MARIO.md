## 🚀 在 UIFlow2 中运行

### 方法一：直接粘贴运行
1. 用 USB-C 连接 Tab5 到电脑
2. 打开 **UIFlow2** (https://flow.m5stack.com)
3. 选择 **Python** 模式
4. 将 `super_mario_tab5.py` 的全部内容粘贴到编辑器
5. 点击 **运行** 按钮

### 方法二：下载到设备
1. 在 UIFlow2 中将代码保存为 `super_mario.py`
2. 下载到 Tab5 设备
3. 重启后自动运行

## 🎯 游戏特性

### 关卡元素
- 🧱 **砖块** — 从下方顶碎可获得 50 分
- ❓ **问号方块** — 顶出金币 (+200分)
- 🪙 **金币** — 收集漂浮金币 (+100分)
- 🟢 **管道** — 世界装饰，不可进入
- 🏳️ **终点旗杆** — 到达即通关 (+2000分)
- 🏰 **城堡** — 关卡终点

### 敌人
- 👾 **栗子怪 (Goomba)** — 踩踏消灭 (+100分)，触碰则受伤

### 物理系统
- 重力 & 跳跃物理
- 可变跳跃高度 (短按小跳 / 长按大跳)
- 加速跑机制
- 平滑镜头跟随

## 🔧 自定义修改

### 修改关卡布局
编辑 `build_level()` 函数中的方块数组：
```python
# 添加砖块
lvl[row][col] = BRICK

# 添加问号方块
lvl[row][col] = QMARK_COIN

# 添加管道 (需要 2 列宽)
lvl[row][col] = PIPE_TL
lvl[row][col+1] = PIPE_TR
```

### 修改物理参数
```python
GRAVITY   = 0.55   # 重力加速度
JUMP_VEL  = -10.5  # 跳跃初速度
MOVE_SPEED = 3     # 走路速度
RUN_SPEED = 5.5    # 跑步速度
```

### 修改马里奥外观
编辑 `MARIO_STAND_R` 精灵数组，每个元组表示 `(x, y, 宽, 高, 颜色)`：
```python
MARIO_STAND_R = [
    (3,0, 10,2, C_RED),   # 帽子
    (4,4, 4,2, C_SKIN),   # 脸
    ...
]
```

## ⚠️ 注意事项

- **显示屏**: 1280×720 横屏 (Rotation=1)
- **帧率**: 目标 ~30-50 FPS (取决于精灵数量)
- **内存**: Canvas 缓冲占用约 1.7 MB (1280×670×2 字节)
- **兼容性**: 需要 LVGL canvas 支持 (UIFlow2 固件 v2.0+)

## 🛠️ 调试

如果游戏卡顿:
1. 减少画布尺寸 (`GAME_W` / `GAME_H`)
2. 降低精灵缩放 (`scale=1` 替代 `scale=2`)
3. 减少同屏敌人数量

如果按钮无响应:
- 检查 LVGL 事件回调是否正确绑定
- 确认 `M5.update()` 在主循环中调用
